**Job Security Score Prediction**

Built a machine learning model to predict Job Security Score using regression techniques. The project involved data cleaning, exploratory data analysis (EDA), feature engineering, and One-Hot Encoding of categorical variables.

Trained and compared Linear Regression, Random Forest Regressor, and XGBoost Regressor. Linear Regression achieved the best performance with an R² score of **0.878** and a 5-fold cross-validation R² score of **0.875**, indicating strong predictive accuracy and generalization.

**Tech Stack:** Python, Pandas, NumPy, Scikit-Learn, XGBoost, Seaborn and  Matplotlib.
